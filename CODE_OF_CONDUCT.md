# Código de conduta

Este projeto deve ser um espaço respeitoso, técnico e colaborativo.

## Comportamentos esperados

- Respeitar opiniões e níveis de experiência diferentes.
- Manter discussões técnicas e objetivas.
- Evitar ataques pessoais.
- Corrigir com educação.
- Priorizar segurança e responsabilidade com dados.

## Comportamentos não aceitos

- Ofensas pessoais.
- Exposição de dados sensíveis.
- Publicação de credenciais.
- Assédio ou discriminação.
- Uso do projeto para prejudicar ambientes de terceiros.

## Aplicação

O mantenedor pode remover comentários, fechar issues ou bloquear interações que violem este código de conduta.
