# Imagens

Esta pasta é reservada para diagramas e capturas de tela **sanitizadas**.

Antes de adicionar uma imagem, confira que ela não mostra:

- endereços IP ou nomes de máquina/usuário reais;
- nomes de coleções, arquivos ou conversas internas;
- brasões, logotipos ou nomes institucionais sem autorização;
- tokens, e-mails ou qualquer dado de produção.

Use dados fictícios e um ambiente de demonstração. Veja o guia de sanitização do
repositório [infra-ti-labs](https://github.com/lteodoro780/infra-ti-labs/blob/main/docs/guia-sanitizacao.md).
